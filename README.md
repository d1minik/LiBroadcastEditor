# LiBroadcastEditor

LiBroadcastEditor is a Chrome extension for customizing the look of Lichess broadcast pages.

## Installation

1. Download the ZIP file that contains the extension code files.
2. Extract the ZIP so all files are inside one folder.
3. Open Chrome and go to `chrome://extensions/`.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted folder that contains `manifest.json`, `popup.html`, `popup.js`, `content.js`, `content.css`, and `shared.js`.
